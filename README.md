# Komentář k zákonu č. 417/2004 Sb., o patentových zástupcích a o změně zákona o opatřeních na ochranu průmyslového vlastnictví

Otevřený komentář k zákonu o patentových zástupcích — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; Komora patentových zástupců, rejstřík, zkoušky, pozastavení a vyškrtnutí, zahraniční zástupci, práva a povinnosti, asistenti a disciplinární řízení.

Konsolidované znění: dokument e-Sbírky `SB-2004-00417_2010-07-01`.
